# ATM-Management-System

## Description
A Java-based ATM Management System developed with GUI support to simulate real-world banking operations such as withdrawal, deposit, balance inquiry, and transaction management.

## Features
- User login authentication
- Cash withdrawal
- Deposit money
- Balance inquiry
- Transaction management
- GUI-based interface

## Technologies Used
- Java
- Swing (GUI)
- OOP Concepts
- File Handling / Database

## How to Run
1. Compile all Java files
2. Run the main Java file
3. Use the GUI interface for ATM operations
